# Fabricante de Ideas

- `kit/` — el kit vigente (`kit/LEEME.md` dice cómo se usa y qué versión es).

- `docs/PROYECTOS.md` — proyectos creados.
- `docs/proyecto/INSTRUCCIONES_PROJECT.md` — instrucciones del Project de claude.ai.
- `docs/CIERRE_SESION.md` — cómo se cierra una sesión.
