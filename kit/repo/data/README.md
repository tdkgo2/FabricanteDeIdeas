# data/

Archivos de datos reales: fuera de git (`.gitignore`). Viven aquí, en el dispositivo, y en la laptop
de {{LIDER}}. La lista de qué existe, con su SHA-256 y su estado, está en `docs/datos/REGISTRO_DATOS.md`:
un archivo que no está en el registro no existe para el proyecto.

`data/reportes/` guarda salidas de consulta (Excel de revisión, exportaciones). Tampoco van a git.
